# Documentation

This folder contains development guides, project plans, and additional documentation for the Playing With Marvel API project.

## Contents

- Development guides and rescue plans
- Architecture decision records (ADRs)
- Migration strategies
- Technical specifications
- Implementation plans

## Organization

Documentation files should be named descriptively and use kebab-case:
- `api-rescue-plan.md` - Plan for handling Marvel API sunset
- `migration-guide.md` - Migration strategies
- `architecture-decisions.md` - Key architectural decisions

For AI assistant guidance, see `/CLAUDE.md` in the project root.
